# 初版指标约定

本文件为初版设计，不是业务方已确认的评分标准。

- 仅在相同平台、相同热度单位和相同统计窗口内比较热度。展示原始值及可比样本数量。
- 平台内百分位建议使用并列中位秩：100 × (小于该值的条数 + 0.5 × 等于该值的条数) / 可比有效条数。只有一条时只展示原始值，不展示百分位排名。
- 曝光、阅读、播放的分母不可混用。互动率声明采用的互动构成和分母；缺失项不能默认 0。
- 增长率仅对可比基期计算：(本期 - 基期) / 基期；基期缺失或为 0 时不计算。
- 跨平台只展示“覆盖几个平台”“几个来源”等明确计数，不直接汇总原始热度，不以来源数量作为真实性证明。
- 营销相关性采用高/中/低的定性判断并说明理由，不输出虚构精确评分。品牌适配必须基于当前项目背景；缺少背景时只输出通用机会。
- 所有数值计算保留输入字段和公式，关键观点回链到事件及来源。
