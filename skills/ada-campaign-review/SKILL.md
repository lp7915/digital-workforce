# 合作策略与效果复盘

## 选择模式
用户尚未投放：输出合作方案与衡量计划。已有活动数据：输出效果复盘。确认目标、品牌/品类、艺人、市场、时间窗、预算口径、渠道、归因窗口和交付形式。先使用已有分析证据；缺少数据时交付假设清单及数据需求，不虚构结果。

## 方案模式
1. 将艺人内容优势与品牌信息对应，提出合作形式、内容主题、触点节奏和受众假设；每个方向说明证据与待测试点。
2. 给出试投、扩量与停止条件，阈值由历史基准或用户业务目标支撑。没有基准时提出待确认目标，不捏造行业标准。
3. 设计衡量表：目标、指标定义、数据源、负责人、采集频次、观察窗口、归因限制。区分自然触达与付费放大、品牌指标与转化指标。
4. 商务报价和预算仅使用已知条件；情景估算列出假设及范围。方案不构成签约、预算审批或对外发送授权。

## 复盘模式
1. 对齐目标、基准和实际数据，核验跨渠道去重、退款、币种、费用包含范围和归因窗口。无法去重时不得宣称独立触达总人数。
2. 计算 CPM=费用/曝光×1000、CPE=费用/约定互动量、ROAS=可归因收入/广告花费。分母为 0 或缺失时不可计算；ROAS 不等于利润 ROI。计算 ROI 须有一致口径的增量利润和成本依据。
3. 区分艺人内容表现、媒介投放和产品/渠道因素；无对照设计时只描述相关变化，不声称因果增量。小样本和选择偏差单独披露。
4. 形成可执行改进项及验证计划。只有用户要求且具备项目写权限时，才将已确认事实写入对应项目记忆；不跨项目沉淀保密数据。

## 交付
输出「决策摘要 → 目标与范围 → 方案或结果对照表 → 关键发现与证据 → 限制 → 下一步行动/负责人/验证指标 → 来源及计算附录」。根据用户需要生成报告或表格，实际产物存在后再提供路径；不声称调用了不存在的数据接口。
