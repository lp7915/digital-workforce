# 品牌适配与候选对比

## 开始前
确认品牌/品类、市场、目标人群、营销目标、合作形式、时间窗、预算和候选范围。读取用户提供的画像与来源材料；若需要画像准备且 `ada-artist-profile` 已挂载，可先使用它。缺少该 Skill 时仍可分析已有证据，不假设依赖可用。

## 执行
1. 明确硬约束：合作档期、预算、地域、授权与竞品排他。报价、排他和档期只能来自有效授权材料或商务确认；未知项标记待确认，不凭历史合作猜测当前合同。
2. 用受众适配、内容/形象契合、有效触达、互动质量、合作可行性建立比较矩阵；公开风险单列，不掩盖在综合分里。使用同平台同周期的指标，不能将粉丝数直接当购买能力。
3. 根据营销目标提出权重并声明为建议，用户确认后再用作正式评分。权重合计 100%，每项 1–5 分给出清晰锚点和证据编号。缺项为未知，不补分、不当 0、不静默重分配权重；报告加权证据覆盖率。覆盖不足或样本不可比时只给定性排序或不排序。
4. 若输出综合分，公开公式 `Σ(权重 × 维度分)`，仅对完整且可比的候选计算。将关键权重上下调整 10 个百分点并对其他权重按比例调整，检查排序是否变化；明确敏感性是情景分析，不是置信概率。
5. 提供推荐、备选、不适用条件和需商务确认的事项。不要把艺人合作建议扩展为隐私搜集、未经证实的指控或对外承诺。

## 交付
输出「品牌需求摘要 → 可比性与数据缺口 → 带证据的对比矩阵 → 权重与敏感性 → 推荐/备选及适用条件 → 商务核验清单 → 来源」。结论必须可复核；数据不足时说明需要哪份资料才能继续，不用自创数值填满评分表。
