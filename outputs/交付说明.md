## 立即使用

```sh
cd /path/to/digital-workforce
npm start
```

当前服务已经运行，无需重复启动。首次或其他浏览器登录时，在本机终端读取 `cat data/admin-token` 并粘贴登录。不要把令牌发送到聊天或写入代码。

后续安装/验证：`npm ci --ignore-scripts`、`npm test`、`npm run check`、`npm run format:check`、`npm run build`。完整操作与配置说明在源码目录的 `README.md`。

## 已实现

- Web：员工创建/详情，Identity与Knowledge草稿、发布、版本对比/切回；项目与群绑定、共享范围、项目管理员权限；记忆来源、纠正、删除、冲突/规则审批；资料索引与撤权；任务状态、重试、Bot心跳；本机令牌认证。
- Gateway：群公共Session共享排队，不同群/话题可并行；每轮固定发布和授权记忆快照，后续轮次刷新；单聊不读取/写入项目共享记忆；全局配置写入权限由服务端隔离。
- Memory：连续空闲至少30秒、无排队/运行/授权等待才执行；冻结增量范围；来源/敏感信息/类型校验；原子幂等提交；冲突不覆盖；撤权/换绑检查；有界重试和真实进程退出恢复。
- Bot：独立测试配置、显式启停、租户/群/用户白名单，复用MA、飞书Channel、流式卡片、表情队列、文件处理、单聊OAuth与Vault链路。未启动真实Bot。

## 尚未验证与首版限制

1. **真实飞书/MA端到端未执行**：缺少独立测试Bot/群及MA资源配置。不会使用旧项目生产身份来补测。所需字段及启动步骤在 `docs/test-bot.example.json` 与README中。
2. 默认提炼只接受明确确认语法，例如 `确认决策：交付日期=10月15日`。可选独立MA适配器筛选这些候选，不代表已完成开放自然语言的自动记忆判断。MA后台无工具override、固定版本和运行环境隔离仍须在测试环境验证。
3. MA原生Memory的只读、动态挂载和更新可见性未验证；首版使用Gateway本地存储与权限过滤，不依赖原生Memory。
4. 事实更正可在原Session下一轮刷新。删除、撤权、换绑或无法安全热更的发布版本会阻止继续复用旧MA上下文，要求显式 `/new`；项目记忆保留，旧Session文件不会自动迁移，也没有自动compact。
5. 后台记忆任务已持久化恢复；真实业务队列沿用上游默认路径，未启用上游实验性durableQueue自动重放。运行结果未知时保守阻止，不伪造成功或盲目重发。
6. 资料索引登记不复制文件字节、不验证远端长期存储；远端删除/撤权目前须在管理台同步，尚未自动订阅权限事件。保留期限、企业SSO和更完整敏感信息策略尚未配置。

## 真实Bot联调入口

```sh
cp docs/test-bot.example.json work/test-bot.json
chmod 600 work/test-bot.json
# 在本机填入独立测试凭据及白名单
npm run bot -- --config work/test-bot.json --check
npm run bot -- --config work/test-bot.json --start
```

`--check` 不连接外部服务。`--start` 才显式连接。Bot与Web分别运行，停止各自终端中的进程即可。当前Web仅监听127.0.0.1，不对公网无认证开放。
