# 三模块前端交付

预览：http://127.0.0.1:8790/#employees 。运行 `npm start` 即可使用现有本机静态资源服务；此次未修改后端代码。页面不调用原业务 API，不读取或更改原 SQLite 业务数据。

## 页面与交互

| 模块 | 已实现前端内容 |
| --- | --- |
| 数字员工列表 | 简洁卡片、搜索、新建、查看详情 |
| 员工详情 | 基础信息、启停状态、身份、知识与规则、技能添加/移除/启停、员工记忆维护、环境配置、凭证引用登记、飞书及豆包配置、版本发布/查看/切换 |
| 项目列表 | 卡片、搜索、新建、名称与描述编辑 |
| 项目详情 | 记忆新增/编辑/删除，群聊关联/编辑/解除，成员添加/移除/权限修改 |
| 运行中的任务 | 执行中与等待中任务卡片、搜索、类型/状态组合筛选、当前进度及步骤详情；演示进度不自动更新 |

项目权限包括查看、改写、管理。改写允许新增、编辑与删除项目记忆；管理增加成员管理。前端阻止移除或降权最后一位管理成员；不允许重复添加同一成员或同一项目群聊。

版本保存配置快照，切换时恢复配置但保留员工记忆与完整版本历史。配置表单有未保存状态和离开确认。凭证只保存 `credential://…` 或 `vault://…` 引用，不提供密钥字段。

## 演示边界与研发接入

数据初始化与持久化入口为 `public/app.js` 的 `seed`、`repository.load`、`repository.save`。当前使用浏览器 localStorage，key 为 `workforce.frontend.v1`；新浏览器使用初始演示数据，刷新保留本浏览器已保存的内容。存储不可用时展示保存失败提示。仅作为前端交互原型，不作为线上身份、权限或密钥存储实现。

目前不发送 HTTP 业务请求，不调用 MA，不启动真实飞书/豆包连接，不进行后台记忆提炼。观测记录为固定演示记录；不会以模拟成功代替真实调用结果。

建议后端接入时：

1. 以员工、项目、观测三个集合对接服务，替换演示数据及同步保存；页面异步等待、错误恢复、加载状态需随真实接口接入。
2. 员工实体包括配置、技能、环境、凭证引用、渠道与版本；员工记忆独立于版本快照。
3. 项目实体包括记忆、群聊和成员。后端对记忆改写与成员管理做权威鉴权，前端按钮可按服务端返回权限显示。
4. 凭证由服务端安全托管，浏览器只持有引用；渠道连接状态、版本发布结果和观测记录以服务端返回值为准。
5. 当前区域/模型字段为演示选项，实际资源列表由后端提供；动态挂载 Memory 与执行链路不在此次前端范围内。

# 记忆结构调整（2026-09-21）

员工与项目采用「记忆库 → 条目（带路径）→ 文本内容」。支持创建及编辑记忆库、条目增删改、修改所属库和路径；库内相对路径唯一，内容按原始文本保存（可填写 Markdown）。旧平铺记忆迁移到默认库，使用 `notes/<原条目 ID>.md` 作为初始路径，原内容保留。

前端字段：`memoryStores: [{ id, name, description }]`；`memories: [{ id, storeId, path, title?, content, source?, updatedAt }]`。记忆库和条目不进入员工配置版本快照。以上是前端模型，未调用 MA；项目记录的官方文档入口未能读取，MA 接口字段及路径限制仍待研发按可访问文档核对，不宣称已完成接口契约验证。

验证：6 项前端测试通过，构建和格式检查通过；浏览器实测员工条目路径编辑、保存与刷新保留。
