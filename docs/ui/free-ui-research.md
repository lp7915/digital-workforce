## 实施方式

现有前端为原生 JS 和 CSS。此轮参考上述布局和组件设计，自行实现样式，没有安装 React shadcn/ui，也没有复制模板源码或引入外部字体、脚本。这样无需改变接口和构建流程。

- 浅灰侧栏、白色工作区，清晰区分全局导航和业务内容。
- 统一灰阶、边框、圆角、阴影和按钮样式，提高辅助文字可读性。
- 卡片统一内边距、悬停反馈；保留整卡点击和独立操作按钮。
- 详情导航采用分段标签，长标签组横向滚动。
- 表单和弹窗保持现有输入、下拉、键盘及保存行为。
- 统一自绘导航描边图标；移动端搜索占满宽度，顶栏允许换行。
- 尊重系统减少动态效果偏好。

未加入无业务依据的统计图或示例指标。后续如果决定迁移 React，可直接评估官方 Sidebar、Tabs、Select、Dialog 的实际组件替换。
