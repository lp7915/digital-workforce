# 项目记忆与群聊工作现场

项目聚焦事情：项目记忆、关联群聊、成员与权限。项目记忆是项目资源，数字员工无需单独加入项目名单。

关联群聊必须在项目内通过飞书 API 查询并再次校验管理权限，保留一个群最多关联一个项目。支持解除关联；不能手填群 ID 登记，也不能通过普通工作台保存伪造群关系。

群聊模块只读展示项目归属和实际在群的数字员工，支持项目/员工筛选。添加、移除机器人在飞书中执行，工作台通过 Bot 进退群事件更新员工在群状态。旧邀请接口返回 405。项目查询关联不会制造机器人在群记录。

会话挂载当前员工自身记忆库 + 当前群所属项目全部记忆库，私聊只挂载自身库。不再检查历史项目员工名单。群归属或记忆库变化后使用 /new。普通 Session 保持只读挂载，项目成员仍控制整理写回权限。

已有飞书应用需订阅 im.chat.member.bot.added_v1 和 im.chat.member.bot.deleted_v1，尚需真实进退群验收。新发现群默认未关联项目，名称未知时显示群 ID。当前 SDK 0.4.1 通过集中 dispatcher 兼容层处理退群，不另开 WebSocket。重复/乱序事件按每群每员工时间戳去重。
